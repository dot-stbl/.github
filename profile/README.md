# `.stbl`

**small studio · infrastructure software**

---

`.stbl` is a hidden file.

In Unix, anything starting with a dot is invisible by default.
`ls` won't show it. `ls -la` will.

`.stbl` is the bottom layer of every product we ship.
You don't see it until you look.
